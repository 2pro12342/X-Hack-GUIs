# X-Hack-GUIs
all hack GUI's from X-Network including; BlooketX, KahootX, Valence (Gimkit), and Rune (Prodigy). 

## BlooketX 
If you are wondering; "Why have the V6 version of the hack GUI client when i can use the V8 version?" Sure the V8 version is good because, it's more updated and it has better features, but the V6 has; 
- A Character Editor
- A Character Customizer
- A Module Manager
  
- Why is this not on the V8 of the GUI client?: In the recent version, the V8 detects CSP for some reason and blocks the customization tab. Also there is no character editor.

## KahootX 
If you are wondering; "Why use this GUI client instead of other Kahoot clients?" Well, this version is updated, has more features, has bot spawning, and has auto-connecting. 

- What is auto-connecting?: This feature allows you to connect easier than most Kahoot GUI's. Most (other) GUI's say to look at the teacher's screen of the Kahoot URL to paste into the GUI on your screen, but this one has easier ways to connect.
